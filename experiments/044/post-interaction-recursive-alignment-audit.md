## 7. Surface-access/delivery/exposure assessment

- **[RECORDED]** The frozen Opportunity Model already states `SURFACE ACCESS ≠ ACTOR ACCESS ≠ INTERVENTION PERMISSION ≠ ACTOR EXPOSURE`.
- **[RECORDED]** README distinguishes `SPECIFICATION ≠ AUTHORIZATION ≠ CAPABILITY ≠ ACCESS`; ARCHITECTURE distinguishes delivery from exposure and later effects.
- **[RECORDED]** Experiment 030 nevertheless demonstrated the missing operational boundary: permitted, successfully published, persistently available delivery still left actor exposure `UNKNOWN`.
- **[DERIVED]** Living operational truth must explicitly preserve `surface access ≠ permission ≠ delivery/publication ≠ exposure` and identify evidence for each state.
- **Primary disposition: UPDATE.** Put the operational distinction in the Operating Model and future actor-facing preregistration convention; do not duplicate detailed rules across every top-level document.

## 8. Exposure-observability disposition

- **[RECORDED]** 030 became measurement-limited because publication offered no actor-specific exposure evidence and silence could not be interpreted.
- **[RECORDED]** 035's semantically specific authoritative response established exposure after the fact without proving a particular notification mechanism.
- **[DERIVED]** Exposure observability is a pre-execution experimentability constraint, not a post-hoc telemetry field.
- **Primary disposition: UPDATE.** Future actor-facing specs should preregister delivery evidence, exposure evidence, whether response can establish exposure, and silence classification when exposure is unavailable.

## 9. Semantic-processing versus human-cognition assessment

- **[UNKNOWN]** The persisted evidence does not establish unaided human authorship or private cognitive change.

## 17. Evidence-chain assessment

Candidate chain:

```text
DELIVERY
→ EXPOSURE
→ SEMANTIC PROCESSING
→ AGENCY / AUTHORITY
→ DECISION-STATE EFFECT
→ OBSERVED ACTION
→ ECONOMIC EFFECT
→ VALUE CAPTURE
```

- **[DERIVED]** The labels expose real non-equivalences, but the arrows overstate a universal order: a substantive response can establish exposure retroactively, authority is provenance rather than a causal stage, and many experiments intentionally stop before downstream economics.
- **Primary disposition: DEFER** promotion of the chain as normative sequence.
- **Secondary disposition: ANNOTATE / SUPERSEDE** 043's provisional chain with a non-rigid evidence-ledger representation in later living policy.

## 18. Evidence-ledger alternative assessment

**Primary disposition: UPDATE.** Use a non-rigid ledger of separable evidence states:

| Evidence state | What must be recorded when relevant |
|---|---|
| Surface access | surface technically available |
| Intervention permission | platform/control/user authorization permits action |
| Delivery/publication | intervention reached the intended surface |
| Exposure | decision channel/actor encountered it, directly or via later semantic response |
| Semantic engagement | response addressed the tested proposition |
| Account/channel identity | identity under which the message appeared |
| Decision authority/accountability | scope in which that identity can speak or act |
| Authorship provenance | disclosed/verified origin or `UNKNOWN`; orthogonal to authority |
| Public decision-state refinement | observable decision object changed |
| Stated intent/next action | action declared, not assumed executed |
| Observed downstream action | independent evidence action occurred |
| Economic effect | consequence measured or `UNKNOWN` |
| Value capture | payment/other capture measured or `UNKNOWN` |

- **[INFERRED]** Each experiment selects the states needed by its hypothesis; `N/A` and `UNKNOWN` remain distinct.
- **[DERIVED]** This avoids recreating the fixed-pipeline assumption rejected by current README, ROADMAP, ARCHITECTURE, and Operating Model.
