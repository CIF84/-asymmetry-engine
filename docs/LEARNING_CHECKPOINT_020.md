## Outcome

Spec 020 returned **C — FAIL** for construction of an EV smart-charging compatibility artifact.

The underlying decision problem survived: configuration-specific compatibility uncertainty is real, economically consequential, observable before purchase or tariff switching, and technically recoverable from authoritative evidence.

The artifact hypothesis did not survive because BecSpec already performs substantially the same bounded UK decision-resolution function contemplated by Specs 019–020.

```text
HYPOTHESIS A
Configuration-level EV smart-charging compatibility
is a genuine derived information problem.

STATUS: strengthened

HYPOTHESIS B
The tested market lacks an adequate bounded resolution.

STATUS: falsified
```

The EV compatibility opportunity family is **PARKED**. Do not rescue it through feature expansion, another EV subproblem, paid traffic, or maintenance research unless independent future evidence establishes a materially different unresolved decision or differentiated distribution/value-capture advantage.

## 1. Exact resolution gap moves earlier

The project spent Spec 019 establishing technical/evidence feasibility before Spec 020 discovered that an essentially equivalent answer already existed.

Spec 019 was still valuable, but future research policy should attempt an exact-resolution search earlier when it is cheap:

```text
friction
  ↓
specific missing information
  ↓
recoverability
  ↓
EXACT RESOLUTION SEARCH
  ↓
residual resolution gap?
  ↓
technical deepening
  ↓
commercial experiment
```

## 2. Functional competition, not category competition

Competition should be evaluated by the decision-resolution function rather than category labels:

```text
ACTOR
  ×
DECISION
  ×
INPUTS
  ×
RESOLUTION
  ×
OUTPUT
  ×
TIMING
```

An existing solution is potentially hypothesis-killing when it substantially performs the same function for the same actor at the same decision point.

This is not a rule to avoid competition.

```text
NO COMPETITION
may mean
unserved opportunity
OR
nobody cares

COMPETITION
may mean
validated value
OR
adequately resolved uncertainty
```

The governing question remains:

> **What economically consequential uncertainty remains inadequately resolved?**

## 3. Failed-measurement stop rule

The bounded DataForSEO request succeeded but keyword rows were not recovered because the response was parsed against the wrong result shape.

Once the exact existing resolution became decisive, repeating the request would no longer have changed the decision.

Preserve:

> **Do not repair a failed measurement merely because it failed. Repair it only if the missing evidence can still change the current decision.**

## 4. RADAR value includes cheap rejection

Spec 020 prevented a plausible path into artifact construction after roughly one hour of bounded research and $0.09 of paid data.

```text
RADAR VALUE
=
opportunities correctly advanced
+
opportunities cheaply rejected
```

Future RADAR evaluation should consider winner discovery together with cost-to-rejection, kill-stage location, and avoided downstream work. No generic quantitative score is authorized yet.

## 5. Updated RADAR → FORGE boundary

A stronger current working sequence is:

```text
credible asymmetry
        ↓
recoverable information
        ↓
economic consequence
        ↓
resolution feasibility
        ↓
pre-decision behavior
        ↓
EXACT RESOLUTION GAP
        ↓
reachable / sufficiently powered experiment
        ↓
FORGE
```

The order may vary when one gate is exceptionally cheap, but a hypothesis should not cross into FORGE merely because the problem is real and technically solvable.

## 6. Updated opportunity anatomy

```text
ECONOMICALLY CONSEQUENTIAL UNCERTAINTY
          ×
RECOVERABLE INFORMATION
          ×
INADEQUATE EXISTING RESOLUTION
          ×
REACHABLE DECISION BEHAVIOR
          ×
PLAUSIBLE VALUE CREATION
```

Eventual economic proof additionally requires plausible value capture.

This is a conceptual model, not a scoring formula.

## 7. Research economics

Spec 020 is classified **HIGH YIELD**.

Observable effort was approximately 50–60 minutes, ~20 targeted searches, ~15 major source inspections, one $0.09 DataForSEO request, no production implementation, and no external outreach.

The result changed the next decision from possible artifact construction to PARK.

This is an example of the intended research-policy loop:

```text
NEXT RESEARCH ACTION
        ↓
maximize expected
DECISION-RELEVANT
uncertainty reduction
```

rather than maximizing accumulated knowledge.
